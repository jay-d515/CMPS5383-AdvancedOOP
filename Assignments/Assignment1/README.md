# Assignment 1 - Designing Interacting Objects
## Main Idea
#### For this assignment, our objective was to practice designing software from an  object-oriented perspective. This meant we picked a scenario that interested us and organized it into classes. Then, identified the relationships between the classes and decided which behaviors should be shared or overridden; and finally, developed interactions between the objects. 
#### I decided to create an object-oriented implementation of the card game Uno where a coordinator class drives automated players through full games using the official rules.

## How to run
#### 1. Open the folder named 'Uno'.
#### 2. Open the file main.py and edit the list players, if you desire.
#### 3. In the terminal, navigate to the Uno folder containing the files: card.py, player.py, game.py, and main.py.
#### 4. type the command 'python3 main.py' into the terminal to run the program.
